# 🐱 Kotogram & KoteLoader Native C++ Modules

Официальный набор нативных высокопроизводительных модулей расширения на **C++ (C-ABI 3)** для Telegram юзербота **Kotogram / KoteLoader**.

**Автор модулей:** [@Diezdd](https://t.me/Diezdd)  
**Архитектура:** Android `arm64-v8a` (minSdk 26) и Linux `x86_64`  
**Стандарт языка:** C++20

## 📦 Список модулей в репозитории

### 1. ✍️ `autosig` — Автоматическая подпись сообщений
Автоматически добавляет форматированную подпись к исходящим сообщениям с защитой от изменения команд юзербота и фильтрацией чатов.

* **Файл библиотеки:** `bin/autosig.so` (arm64-v8a)
* **Исходный код:** `src/autosig.cpp`
* **Команды:**
  * `.autosig` / `.sig [on|off]` — включение / выключение автоподписи или переключение режима.
  * `.setsig <текст>` — установить глобальный текст подписи (поддержка Markdown, ссылок, кастомных эмодзи Telegram Premium).
  * `.getsig` — просмотр текущих настроек, позиции и текста подписи.
  * `.sigpos <start|end|both>` — положение подписи (в начале сообщения, в конце или с двух сторон).
  * `.sigchat [set|del|here] [id] [текст]` — персональная подпись для конкретного чата (переопределяет глобальную).
* **Интерактивные настройки (`.cfg`):** тумблеры применения в ЛС, группах и каналах.

### 2. 🎵 `music_dl` — Музыкальный поисковик и загрузчик
Поиск и скачивание музыки из SoundCloud и Spotify напрямую в чат Telegram.

* **Файл библиотеки:** `bin/music_dl.so` (arm64-v8a)
* **Исходный код:** `src/music_dl.cpp`
* **Особенности:**
  * **Автоматическое самовосстановление SoundCloud Client ID:** при устаревании ключа модуль динамически считывает актуальные JS-бандлы с `soundcloud.com` и обновляет ключ в локальной SQLite базе данных.
  * Скачивает поток и отправляет нативный аудиофайл через `c_send_file` с автоматической очисткой временных файлов.
* **Команды:**
  * `.find <запрос>` — поиск треков с нумерованным списком, длительностью и количеством лайков.
  * `.fc [next|prev]` — пагинация результатов текущего поиска.
  * `dlf <номер>` — скачать трек под указанным номером из последнего поиска.
  * `.download <запрос>` / `.msc <запрос>` — быстрый поиск и мгновенная отправка первого совпадения.
  * `.like <номер>` — добавить трек в постоянное «Избранное».
  * `.favs` — список сохранённых треков.
  * `.musicinfo` — статистика и параметры модуля.

### 3. 🎧 `reswaga` — Now Playing карточка играющего трека
Интерактивная карточка воспроизводимой музыки со ссылками на прослушивание.

* **Файл библиотеки:** `bin/reswaga.so` (arm64-v8a)
* **Исходный код:** `src/reswaga.cpp`
* **Поддерживаемые платформы:** Last.fm (универсально для любых плееров: Яндекс.Музыка, Spotify, Apple Music, VK, Android/PC плееры), Stats.fm (Spotify).
* **Команды:**
  * `.now` / `.np` — текстовая карточка играющего сейчас трека:
    * Кастом-эмодзи Telegram Premium
    * Название трека, автор, альбом
    * Визуальный таймлайн: `▶️ 🔘──────── 01:23 / 03:45`
    * Прямая ссылка на стриминг + универсальная мультиссылка SongLink (`https://song.link/...`)
  * `.npcard` — отправка карточки вместе с оригинальной обложкой альбома в высоком качестве.
  * `.setlastfm <username> [api_key]` — быстрая привязка аккаунта Last.fm.
  * `.setstatsfm <username>` — привязка аккаунта Stats.fm (Spotify).
  * `.npplatform <lastfm|spotify>` — переключение источника данных.
  * `.npinfo` — статус и справка.

## 📲 Установка в Kotogram / KoteLoader

### Способ 1: Через Telegram (в 1 клик)
1. Отправьте файл модуля (`autosig.so`, `music_dl.so` или `reswaga.so`) из папки `bin/` документом в любой чат Telegram (например, в **«Избранное»**).
2. Ответьте на полученное сообщение командой:
   ```
   .install
   ```
3. Модуль мгновенно активируется и появится в `.modules` и `.help` без перезапуска приложения!

### Способ 2: Онлайн-обновления через Git
В приложении Kotogram откройте карточку модуля во вкладке **«Модули»** и нажмите **«Обновить из Git»** (репозиторий `https://github.com/Skwiziii/kt-Modules` автоматически привязан в коде каждого модуля).

## 🛠 Сборка из исходников

Для сборки модулей используется универсальный скрипт `build.sh`:

```bash
# Сборка под Android arm64-v8a (через Android NDK Clang):
./build.sh --android

# Сборка под Linux Host (x86_64 через g++):
./build.sh --host

# Сборка конкретного файла:
./build.sh src/music_dl.cpp --android
```
